# 工具与安全

> 上级：[README](../README.md) ｜ 相关：[部署](部署.md)、[测试](测试.md)（工具链与磁盘工具的 guest 内实测）

| 工具 | 作用 | 限制 |
|------|------|------|
| `system_probe` | 内核/CPU/内存/网络/块设备/挂载点 + payload 文件清单 | 只读 |
| `fs_read` | 读文件或列目录 | 仅 `payload_dir` 内，单次 ≤1MB，二进制转 hexdump |
| `fs_write` | 写普通文件 | 仅 `payload_dir` 内；diff 预览 + 确认；原文件备份 `.bak`；原子写（tmp+rename） |
| `run_command` | 执行命令（无 shell） | 只读白名单直执（`find` 仅在不带 `-exec`/`-delete` 等参数时算只读）；其余需确认；shell 类命令（`sh`/`python`/`xargs`…）仅 `direct` 模式放行；命令名禁止路径分隔符 |
| `ask_user` | 向用户提问 | 脚本模式下返回"无法交互" |
| `schedule_boot` | 写 `ventoy.json`：`control.VTOY_DEFAULT_IMAGE` + `VTOY_MENU_TIMEOUT`，并按 `autosel` 挂自动安装模板（`timeout<0` 时省略该键 ⇒ 不显示模板菜单，Ventoy 插件默认即 -1） | 需输入 `REBOOT` 确认（direct 模式除外）；写前备份、写后重启 |
| `list_disks` | 枚举整盘/分区及结构化信息：容量、型号、总线、分区表、分区的文件系统/卷标/UUID/挂载点、`serial`/`wwid`；`protected=true` 表示禁止改动 | 只读 |
| `partition` | 对整盘重建分区表并创建分区（parted） | 只接受整盘；`protected` 设备一律拒绝；orchestrate 下需**逐字输入盘名**确认；parted 命令由本工具拼装（参数白名单） |
| `format` | 在分区/裸盘上建 ext2/3/4（内置 e2fsprogs）或 vfat（内置 busybox `mkfs.vfat`，用于 UEFI ESP） | 已挂载、承载 payload/根、整盘有分区的目标一律拒绝；orchestrate 下需逐字输入设备名确认 |
| `backup` | rsync 把 `src`（默认 payload_dir）内容同步到 `dst` | 拒写向承载 payload/根的盘（含同一物理盘）；`--delete` 要求 `dst` 是挂载点；确认后才执行 |
| `gen_autoinstall` | 确定性生成 Ubuntu autoinstall 应答脚本（cloud-config）：**选盘用磁盘序列号 serial、挂载用卷标 label**，字段符合 curtin schema（`disk` / `partition` / `format.volume` / `mount`） | 只写 `payload_dir` 内；目标盘必须是整盘且非 `protected`；镜像必须存在；diff 预览 + 确认 |

日志：每轮会话在 `log_dir` 生成 `session-<时间戳>.jsonl`（机器可读）与 `.md`（人可读，含工具调用与 diff）。

## 内置工具链（分区/格式化/备份）

initramfs 随包携带一套**全静态**工具（`pack/build_tools.sh` 构建，装到 `/bin` 以覆盖 busybox 同名
applet 的符号链接），`run_command` / `!命令` 可直接调用：

| 二进制 | 版本 | 说明 |
|--------|------|------|
| `mke2fs`（含 `mkfs.ext2/3/4` 别名） / `e2fsck`（含 `fsck.ext2/3/4` 别名） / `resize2fs` / `tune2fs` / `dumpe2fs` | e2fsprogs 1.47.0 | 建/查/扩/调参/导出 ext2-4 |
| `parted` | GNU parted 3.6 | 建分区表与分区（编译时 `--disable-device-mapper --without-readline`） |
| `rsync` | 3.2.7 | 备份/同步（内置 popt/zlib，无 openssl/acl/xattr） |

7 个二进制合计约 10.5MB（压缩后 initramfs 约 +4.6MB）。`pack_env.sh` 找不到 `$BUILD/tools/` 时只警告
（降级为 busybox 自带 applet）。安装到 `/bin` 而非 `/sbin`（`run_command` 的 `PATH=/bin:/sbin:...` 让
`/bin` 优先），且必须先 `rm` 再 `cp`（否则 `cp` 会穿透 busybox 的符号链接写到本体）。

## 磁盘工具的三层防护

1. **硬守卫（任何模式都生效）**：承载 payload（`/iso`）与根文件系统的设备、已挂载的设备、以及"其上有
   分区被挂载"的整盘，一律拒绝改分区/格式化；`backup` 拒绝写向承载 payload/根的盘（含同一物理盘）。
   `List` 的 `protected` 标记与写守卫共用同一份 `protectionOf`，不会漂移。
2. **参数白名单**：所有写操作的 argv 由 `agent/internal/disk/` 拼装，用户字符串只允许落在白名单内
   （设备路径、卷标、分区名），文件系统只允许 ext2/3/4/vfat、分区表只允许 gpt/msdos；一律
   `exec.Command(argv)` 直接执行、不经 shell，因此无法注入元字符或自定义危险开关。
3. **交互确认**：`orchestrate`（默认）下 `partition`/`format` 要求**逐字输入目标设备名**（如 `vdb`），
   `backup` 要求 y/N（带 `--delete` 时同样逐字确认）；`direct` 模式视为已授权、跳过确认；`readonly`
   直接拒绝。确认前会先展示将执行的确切命令（`steps`）。

容量与对齐：分区从 1MiB 起、按 MiB 向上取整，`size` 支持 `100MiB`/`8G`/`rest`（`rest` 只能放最后）。
`partition` 的 `fs` 仅作 parted 的类型提示（`vfat` 映射为 `fat32`）；`format` 支持 ext2/3/4 与 vfat
（FAT 卷标上限 11 字符），exFAT/NTFS 需另行内置对应工具。`gen_autoinstall` 生成模板用 `serial` 选盘、
用卷标挂载（curtin 的 `disk` 没有 UUID 匹配——空盘在选盘时还没有文件系统；UUID 用在装完后的 fstab）。
