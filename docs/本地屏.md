# 本地屏（交互与拼音输入法）

> 上级：[README](../README.md) ｜ 相关：[部署](部署.md)（`VTOY_AI_SCREEN` 等环境变量）

## 本地屏交互（模式切换 / 历史 / 固定输入行）

只作用于自绘屏幕路径（本地显示器 + 键盘；串口/文本控制台不涉及）。底部固定两行：倒数第二行是
**输入行**、最后一行是**状态栏**；内容输出只滚动上方的内容区，不会把输入行和状态栏冲掉。输入超宽时
输入行自身水平滑动。

| 按键 | 行为 |
|------|------|
| `Ctrl+T` | AI / 命令模式间切换（已输入的文本带到新模式继续编辑） |
| `Tab` | 命令补全：行首补 busybox applet 名，其余词补文件路径（相对路径基于当前目录）；唯一候选直接补全（目录补 `/`），多候选先补公共前缀，**再按一次 Tab** 把候选列到内容区 |
| `cd <目录>` | 命令模式切换工作目录（`run_command` 与路径补全都用它；空参数回 `/`） |
| `↑` `↓` | 浏览历史输入：AI 与命令**各一份**（≤100 条，连续重复合并，退到底恢复草稿） |
| `Shift+↑` `Shift+↓` | 回看逐行滚动（`PageUp`/`PageDown` 翻页，按其它键回到最新） |
| `Ctrl-Space` | 切换中/英输入法（仅内置输入法可用时；状态栏有提示） |
| `Ctrl-U` `Ctrl-C` `Ctrl-D` | 清行 / 中断当前行 / 空行退出 |

- AI 模式：提示符 `你> `（青色），输入发给模型，状态栏左侧 `[AI] <模型>`
- 命令模式：提示符 `$ `（绿色），输入按 `!命令` 的规则直接执行本地命令（不经模型，也不进模型上下文），
  状态栏左侧 `[命令] <当前目录>`
- 状态栏统一样式：` <模式> · 安全模式 <readonly|orchestrate|direct> │ Tab 补全 │ Ctrl+T 切换模式 │ ↑↓ 历史 │ Ctrl+Space 中/英 `

**为什么不是 Shift+Tab 切模式**：本地屏走的是 Linux 控制台（VT）键盘映射，实测**无法区分 Shift+Tab 与 Tab**；
`ESC[Z` 是 xterm 的约定，只在**串口/文本终端**路径可见（那条路径上 Shift+Tab 与 `Ctrl+T` 都可用）。

## 内置拼音输入法（本地屏）

**只作用于自绘屏幕路径**。引擎为 [libgooglepinyin](https://github.com/pinyin/googlepinyin)（Apache-2.0，
许可证见 [`ime/LICENSE`](../ime/LICENSE)）：helper `ime/pinyin-ime.cpp` 静态封装该库，通过 stdio/TSV 协议
（`S` 检索候选 / `A` 选字 / `R` 复位 / `Q` 退出）提供候选；Go 侧 `agent/internal/screen/ime.go` 懒启动
（首次 Ctrl-Space）、单次请求 500ms 超时、组件缺失或握手失败即降级为无输入法（提示一行后不再重试）。

按键（中/英状态存于屏幕对象，**跨行保持**）：

| 按键 | 行为 |
|------|------|
| `Ctrl-Space` | 切换中/英（开时提示符后显示灰色 ` [中]`） |
| `a-z` `'` | 组合拼音（灰色拼音串 + 白色候选条 `1.候选 2.候选…`，最多 9 个） |
| `1-9` | 提交对应候选（越界忽略） |
| `空格` | 提交首选候选；无候选时按原样上屏（英文空格） |
| `回车` | 有候选时提交首选词并送行；无候选直接送行 |
| `退格` | 组合中退拼音（退空则退出组合）；无组合按整字符删 |
| `Ctrl-U` | 清行（连同组合一起清） |
| `A-Z` 等 | 直通进 buf，不参与拼音组合 |

环境变量（均可选）：

| 变量 | 默认 | 说明 |
|------|------|------|
| `VTOY_AI_IME` | 空 | `0` 禁用（不探测、不启动） |
| `VTOY_AI_IME_BIN` | `/ventoy/ai/ime/pinyin-ime` | helper 路径 |
| `VTOY_AI_IME_DICT` | `/ventoy/ai/ime/dict_pinyin.dat` | 主词典路径 |
| `VTOY_AI_IME_USERDICT` | `$TMPDIR/pinyin-user.dat` | 用户词典（选字学习）；tmpfs 内，**重启不保留** |

限制：单字/短语级前缀联想（`im_search`），无云输入、无模糊音、无翻页（>9 候选不翻页）；不做词库
持久化；大写字母直通（便于随时敲英文/路径），小写英文需先 `Ctrl-Space` 切到英模式再输入。

## 点阵字体（本地屏）

自绘屏幕用 GNU Unifont 转换的点阵字体渲染（16×16 中文 + 8×16 英文混宽，VTF1 格式），随 initramfs
携带在 `/ventoy/ai/screen/font.bin`——**独立数据文件，不嵌入 agent 二进制**（来源与 GPL-2.0
许可说明见同目录 `LICENSE.unifont`）。字体文件缺失或损坏时自动降级为文本控制台，串口路径不受影响。

| 变量 | 默认 | 说明 |
|------|------|------|
| `VTOY_AI_FONT` | `/ventoy/ai/screen/font.bin` | 点阵字体路径（测试/调试可覆盖） |
