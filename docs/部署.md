# 部署（T1 入口与数据分区配置）

> 上级：[README](../README.md) ｜ 前置约定：下文 `$AI` 指本仓根目录、`$BUILD` 指构建目录（解析规则见 README「构建」一节）｜ 相关：[本地屏](本地屏.md)、[工具与安全](工具与安全.md)

## T1 入口：AI 环境 mini-ISO 部署

把 AI 环境打成**普通 mini-ISO**，放到 Ventoy 数据分区（part1）根目录，**零 Ventoy 代码改动**即可从
菜单启动；文件名加 `0-` 前缀可让菜单排序在最前。

```sh
$AI/pack/make_iso.sh     # 产物 $BUILD/test/0-OS-PILOT-AI.iso
cp $BUILD/test/0-OS-PILOT-AI.iso /media/$USER/Ventoy/0-OS-PILOT-AI.iso
```

真实机（显示器 + 键盘）注意几点：

- **界面落在哪个 console**：agent 读写 `/dev/console`，它由内核参数里**最后一个** `console=` 决定。
  默认命令行就是真机取向（`console=ttyS0,115200 console=tty0` ⇒ 界面在显示器）。QEMU 无头运行要抓
  **用户态**输出时，用 `VTOY_AI_CMDLINE="console=tty0 console=ttyS0,115200 loglevel=3 rdinit=/init vtoy_ai=1"` 重新生成 ISO。
- **显示器上的中文**：fbcon 自带字体没有 CJK 字形（内核 vt.c 只支持 512 字形且无混宽）。agent 检测到
  **本地显示器为前景控制台**（`/dev/console` 指向 tty0、`/dev/fb0` 可用）时**自绘屏幕**：接管 `/dev/tty0`
  直接画 `/dev/fb0`，用随包携带的 GNU Unifont 点阵字体（`/ventoy/ai/screen/font.bin`，16×16 中文 +
  8×16 英文混宽）；串口路径不受影响。
  `VTOY_AI_SCREEN=fb` 可强制接管（失败即报错），`=0` 可禁用。
- **中文输入**：本地屏**已内置拼音输入法**（`Ctrl-Space` 切换中/英）；串口路径仍由宿主机输入法送
  UTF-8 字节；脚本模式按 `/ventoy/ai/test_script.txt` 的 UTF-8 中文行对话。
- **网络**：需要有**线网 + DHCP**（模块集覆盖常见有线/USB 网卡，**没有 WiFi**）。
- **显示**：真机 UEFI 下帧缓冲由内核内建 `simpledrm`（UEFI GOP）提供；未随包携带 GPU 驱动（体积大且
  需要 `/lib/firmware`），legacy BIOS/CSM 老机器无 fb0 时回退文本控制台（中文受限，功能可用）。

数据分区还要放一份 `/ventoy/ai.json`（真实模型配置，见 [`config/ai.json.example`](../config/ai.json.example)；
https 端点可直连，CA 根证书已打进 initramfs）。`/ventoy/ventoy.json` 建议包含：

```json
{
    "control": [
        { "VTOY_MENU_TIMEOUT": "10" },
        { "VTOY_DEFAULT_IMAGE": "/0-OS-PILOT-AI.iso" },
        { "VTOY_SECONDARY_BOOT_MENU": "0" }
    ]
}
```

两条实测踩坑（Ventoy 1.1.05）：

- **`VTOY_SECONDARY_BOOT_MENU` 要显式设为 `"0"`**：1.1.05 默认开启「二级动作菜单」（Normal/grub2/memdisk/…），
  该菜单**没有倒计时**，会把无人值守启动卡住。替代：设 `VTOY_SECONDARY_TIMEOUT`，或给文件名加 `_vtnormal` 后缀。
- **`ventoy.json` 里不能出现负数**：Ventoy 的 JSON 解析器把 `-` 开头交给 `grub_strtoul`，解析失败会让
  **整份配置失效**。因此 `schedule_boot` 在 `timeout < 0` 时**省略该键**——Ventoy 插件内默认值即 `-1`，语义等价。

## 配置（数据分区 `/ventoy/ai.json`）

关键字段见 [`config/ai.json.example`](../config/ai.json.example)：`base_url` `model` `api_key` `mode`
`payload_dir`（默认 `/iso`）`log_dir`（默认 `/iso/ventoy/ai/logs`）`http_proxy` `request_timeout`。
`api_key` 为空时回退读取环境变量 `VTOY_AI_API_KEY`（Ollama 等本地端点可留空）。

- `mode`: `readonly` 只读 / `orchestrate` 写操作需确认（默认）/ `direct` 直接执行
- 调试开关：`--no-reboot` 或 `VTOY_AI_NO_REBOOT=1` 时 `schedule_boot` 只写配置不重启
